# calculator

Entrepreneur Calculator

## Getting Started

This calculator app demonstrates a clean and maintainable architecture using Flutter and adhering to SOLID principles.
 * Key Features:
   * Basic arithmetic operations (+, -, *, /)
   * Clear button to reset calculations
   * User-friendly interface with a focus on readability
 * Implementation:
   * ValueNotifier: Employs ValueNotifier to efficiently manage and update the displayed result, ensuring optimal performance.
   * SOLID Principles:
     * Single Responsibility: Each class has a single, well-defined responsibility.
     * Open/Closed Principle: The app is designed for easy extension of functionality without modifying existing code.
     * Liskov Substitution Principle: Subclasses can be used interchangeably with their parent classes without affecting the correctness of the program.
     * Interface Segregation Principle: Interfaces are kept small and specific, reducing dependencies.
     * Dependency Inversion Principle: High-level modules should not depend on low-level modules. Both should depend on abstractions.
This app is a practical example of building a robust and scalable application in Flutter using best practices and design principles.
